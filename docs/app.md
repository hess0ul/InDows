# InDows — desktop app

The InDows companion app: a WPF desktop UI that **configures and builds** the install media
(`autounattend.xml`) from a curated, categorised checklist, and **restores** a ReDows backup on a
freshly-installed PC. It is the graphical front-end over the same declarative artifacts published at
[github.com/hess0ul/InDows](https://github.com/hess0ul/InDows).

## Architecture

"1 engine, N facades, 0 duplication" — the same shape as ReDows.

| Project                         | Role                                                                                    |
| ------------------------------- | --------------------------------------------------------------------------------------- |
| `src/InDows.Core`               | Pure engine: catalog, autounattend generation, restore contracts — **no Windows APIs**  |
| `src/InDows.Providers.Windows`  | Windows access: machine context, restore runner (SHA-256 verify, AES-256 vault)         |
| `src/InDows.Gui`                | WPF desktop app `indows-gui.exe` — MVVM, dependency-free theme                           |
| `tests/InDows.Gui.Tests`        | Engine + view-model tests off fakes (no window or disk)                                  |

The Build screen grafts the selected modules onto the bundled base (`data/autounattend.base.xml`)
using the module catalog (`data/modules.catalog.json`, generated by `tools/gen-catalog.ps1` from the
public `modules/` folder).

## Build & test

```shell
dotnet build InDows.slnx
dotnet test InDows.slnx
```

## Self-contained release (no .NET needed on the target PC)

```shell
dotnet publish src/InDows.Gui/InDows.Gui.csproj -c Release -r win-x64 --self-contained true ^
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -p:EnableCompressionInSingleFile=true
```

Produces `indows-gui.exe` (~69 MB) plus the `data/` folder next to it — ship the whole publish folder.

## Regenerate the module catalog

After editing the public `modules/`, rebuild the bundled catalog + base:

```shell
pwsh ./tools/gen-catalog.ps1
```
